# Orion Technik - Brand Assets & Logos Guide

Drop your official brand image files directly into the following directories:

## 1. Logos
- **Primary Header Logo (Light backgrounds)**:
  `public/logos/orion-technik-logo.svg` (or `.png`)
- **White / Inverted Logo (Dark backgrounds & Footer)**:
  `public/logos/orion-technik-logo-white.svg` (or `.png`)

## 2. Favicons & App Icons
- **Favicon**:
  `public/favicon.ico` or `public/icon.svg` (32x32 / 48x48)
- **Apple Touch Icon**:
  `public/apple-icon.png` (180x180)

## 3. Imagery
- **Hero Aircraft Image**:
  `public/images/hero-aircraft.jpg` (High-res 1920x1080 or 2560x1440)
- **World Map Background**:
  `public/images/world-map-dots.svg`

The Next.js application is already configured to automatically read these paths and serve optimized versions.
